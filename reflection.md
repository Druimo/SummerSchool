# Final Reflection: Agents in Computational Biology

I would definitely trust an agent to handle all routine tasks, such as basic code formatting, building loops and logic, and file organization (all under my supervision and according to my instructions). I would rely on it when asking for explanations of script commands or functions, and I would try to engage in debate to keep the agent as critical as possible. I would definitely not trust it with the main research plan or the strategy to adopt. I would never trust code produced on the first attempt without first analyzing and fully understanding it. I would use multiple versions of the agent or different agents to evaluate the work done and to compare with different agents. I would not trust it with complex ideas or interpretations, nor with concepts for which I need a solid theoretical foundation that needs to be studied, but for which I find an agent-based starting point useful. I would ask the agent for confirmation multiple times and reiterate my requests to see if the agent remained consistent with my initial request and did not completely change its mind during the conversation.
